# Handling Missing Data in ETL – Assignment

## About the Assignment

This repository contains my assignment on **Handling Missing Data in ETL**.

The assignment explains why missing data occurs in ETL pipelines and discusses different techniques for handling missing values, such as listwise deletion, column deletion, median imputation, forward fill, and missing data flagging.

## Assignment Topics

The assignment covers the following topics:

1. Reasons for missing data in ETL pipelines
2. Problems with blindly deleting missing data
3. Listwise deletion and column deletion
4. Median imputation for skewed data
5. Forward fill
6. Flagging missing values
7. Business insights from missing data
8. Listwise deletion using a customer dataset
9. Forward fill on Monthly_Sales
10. Missing Income flagging
